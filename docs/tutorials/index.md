# Tutorials

These tutorials show the prompts and review points for common CodeOps workflows. They assume the
plugin is [installed](/installation), its hooks are trusted, and the work happens in a Git
repository.

| Tutorial | Start here when… |
|---|---|
| [Plan a new feature](new-feature.md) | You have an idea or requirement but no implementation plan |
| [Reverse-engineer a codebase](existing-codebase.md) | Existing behavior must become explicit requirements |
| [Execute a plan safely](execute-plan.md) | A CodeOps execution plan is ready to implement |
| [Migrate from Claude](migrate-from-claude.md) | Existing Claude CodeOps artifacts will move to Codex |

For the complete workflow in one page, use the [complex-project quick start](/tutorial).
