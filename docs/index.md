## One workflow from intent to verified software

```text
Idea or existing system
  → requirements discovery
  → recursive ambiguity closure
  → specifications and execution plan
  → adversarial preflight
  → specification tests
  → implementation and verification
  → independent review
  → durable project tracking
```

CodeOps is an installable plugin for Codex. Its skills guide Codex through this workflow while its
coding and output standards load at the start of each trusted session.

Start with [installation](/installation), then follow the [complex-project quick start](/tutorial).
If you already know what you need, use the [skill chooser](/guide/choosing-a-skill).
