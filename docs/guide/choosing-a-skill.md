# Choose a skill

| You want to… | Use |
|---|---|
| Interrogate a vague design before documenting it | [`grill-me`](/skills/grill-me) |
| Turn an idea into formal requirements | [`make-requirements`](/skills/make-requirements) |
| Recover requirements from an existing system | [`retro-requirements`](/skills/retro-requirements) |
| Produce an implementation-ready plan | [`make-plan`](/skills/make-plan) |
| Audit requirements, a plan, or another artifact | [`preflight`](/skills/preflight) |
| Implement an existing CodeOps plan | [`exec-plan`](/skills/exec-plan) |
| Initialize or migrate the CodeOps project layout | [`setup-codeops`](/skills/setup-codeops) |
| Configure specialist Codex agents | [`setup-routing`](/skills/setup-routing) |
| Create or refresh repository guidance | [`analyze-project`](/skills/analyze-project) |
| Track features and portfolio status | [`roadmap`](/skills/roadmap) |
| Maintain architecture docs and ADRs | [`techdocs`](/skills/techdocs) |
| Upgrade older CodeOps artifacts | [`upgrade-plan`](/skills/upgrade-plan) |
| Improve source comments without changing behavior | [`clean-comments`](/skills/clean-comments) |
| Verify and commit repository changes safely | [`git-commit`](/skills/git-commit) |
| Inspect, close, or reopen GitHub issues | [`github-issues`](/skills/github-issues) |
| Review local workflow outcome evidence | [`outcome-review`](/skills/outcome-review) |

You can invoke a skill by naming it naturally:

```text
Use make-plan for the billing-retries feature.
```

Add supported flags as exact standalone tokens:

```text
Use make-plan --auto-design for the billing-retries feature.
```

See [flags and modes](/reference/flags) for the shared controls.
