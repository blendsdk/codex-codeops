# `outcome-review`

Use `outcome-review` to examine local CodeOps workflow evidence for planning accuracy, verification
quality, rework, and escaped findings.

```text
Use outcome-review for the last completed feature.
```

Useful measures include planned versus verified tasks, first-pass verification rate, review cycles,
escaped critical or major findings, ambiguity reopened during execution, and repeated manual
corrections.

The review distinguishes plugin-level workflow problems from project-specific configuration and
recommends changes only when evidence supports them. It reads local, content-free outcome data and
does not upload project material. Invocation counts alone are not treated as quality evidence.
